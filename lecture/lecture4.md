# attention的替代方法
- 当前问题：
1. 上下文窗口的增长(token数量在不断的增加)
2. attention的消耗过大因为是二次方增长
## linear attention
- 改变attention计算的顺序：$$(QK^\top)V = Q(K^\top V)$$，这样复杂度便会由：$N^2 d_k + N^2 d_v$ 降至 $2N d_v d_k$，开销变为了O(N)

## RNN Duality
- 训练的时候(包括前向/反向传播)会全速并行(就像transformer一样)，聊天的时候像RNN一样只有很小的内存，然后把第N个词与只有一个矩阵进行交互算出最新的，而不用往回看前面全部的token
- transformer的问题：每一次有新的词加入就需要把所有之前的词拿出来算一次
- RNN Daulity只会存在固定大小的词在手上，把后面加入的词融合入前面的词之中，就像RNN一样
- 为什么不会像原本RNN一样的问题(上下文遗忘)：
1. 传统RNN只是一个一维的向量，但是RNN Duality是一个二维矩阵，记忆空间的容量呈平方级增长
2. 传统RNN是因为反向传播导致模型难以利用以前的内容，但是对偶模型在训练的时候是transform的形式，不会有反向传播传不到的问题
3. 传统的RNN是对于所有的token进行一视同仁，但是新的框架是有着选择性的过滤，例如遇到"地","得","的"之类的词的时候会把门关闭不写入

# MoE
- 希望能够保持单个的token计算量不增加，MoE将传统的前馈网络变为多个独立的专家网络，同时引入一个路由网络来进行分辨去哪个专家网络
## 三种路由的范式
1. token选择expert：每个token独立计算同时匹配到n个专家，优点为在生成单token的场景下可以无缝运行，缺点为会导致少数的热门专家被token挤爆，而冷门专家没有人选择
2. expert选择token：每个专家主动挑选得分最高的token，优点为计算均衡，每个专家都能用到，缺点为在推理的时候由于只会产生一个token，没有足够的token给专家去挑，有些token难以被选择到，导致信息的丢失
3. 使用路由进行全局指派，达到在全局下配对分数的最大化，优点为没有token被遗弃，缺点为不适合在线推理，单token部分和全局最优
## 离散路由的选择机制
- top-k是不可导的，因为在决定完给哪个专家后需要用top-k来进行截断(要么是0，要么是1)，这会导致路由网络将会难以学习怎么进行选择
1. 强化学习：将路由网路视为策略网络，将token分配视为action，loss下降的程度视为reward，但是这样方差很大，难以学会
2. 在输出logits后，计算top-k前加入可学习的高斯噪音，使得原本的硬边界变得模糊，让没有选择到的专家也有概率被触发
3. 启发式辅助loss，给模型设置的一个惩罚机制，如果分配均匀边会使得loss变小，训练的目标是让loss越小越好
